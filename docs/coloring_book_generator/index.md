🖍️ Draw-a-Book – AI-Powered Coloring Book Generator  

Draw-a-Book is a fun, creative, and interactive web application designed to help users—especially children, parents, and educators—generate personalized black-and-white coloring pages using the power of AI. With a bright, kid-friendly interface and intuitive design, this app turns any idea into printable art for coloring books.

✨ Features:  

🎨 Creative Idea Generator  

Users input a theme (e.g., "Jungle Adventures" or "Magical Creatures") and the app uses GPT-4 to generate imaginative coloring page ideas.

🧠 AI Image Generation  

Each idea is transformed into a black-and-white, line-art image using OpenAI's DALL·E model, perfect for coloring.

📁 Session Saving and Management  

Users can save generated content into named sessions, browse past creations, and delete sessions when no longer needed.

🔐 Secure API Usage  

The app requires the user to provide their own OpenAI API key before access is granted, ensuring safe and independent API usage.

🧒 Kid-Friendly UI  

The application features a colorful, playful design with icons and vibrant buttons to make it engaging for young users and families.

🚀 Tech Stack:  

Python + Streamlit for the interactive frontend

OpenAI GPT-4 + DALL·E 3 for text and image generation

Custom Session Manager for organizing and persisting user creations

Fully responsive and deployable on platforms like Streamlit Cloud or Hugging Face Spaces

🌈 Why It Stands Out:  

Draw-a-Book empowers kids (and the young-at-heart) to co-create with AI. It encourages creativity, storytelling, and hands-on activity—bridging technology with traditional fun through coloring books. Whether for educational use, rainy-day activities, or sparking creative thinking, this app is a perfect example of AI enhancing creativity in an accessible, meaningful way.
